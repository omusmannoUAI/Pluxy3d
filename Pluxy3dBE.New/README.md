Pluxy3dBE.New

Minimal Web API project that reuses domain/repository projects from the monorepo.

Run locally:

1. dotnet build Pluxy3dBE.New/Pluxy3dBE.New.csproj
2. dotnet run --project Pluxy3dBE.New/Pluxy3dBE.New.csproj

This project targets net9.0 to be compatible with the existing projects in the repo.
